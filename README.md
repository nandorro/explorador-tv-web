# Explorador TV Web

Gestor de archivos y editor de texto en el navegador (Chrome/Edge), con teclado o mando.
Limitaciones: sin 7z/RAR ni visor de Office (usa la app Android).

Seleccion: mantener 1 s (o Enter 1 s) selecciona; luego tocar marca/desmarca. Barra superior: Seleccionar todo, Copiar, Cortar, Duplicar, Renombrar, Eliminar. Atajos: Ctrl+A, Ctrl+C, Ctrl+X, Ctrl+D, Ctrl+V.
